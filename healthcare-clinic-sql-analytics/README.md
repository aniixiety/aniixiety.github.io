# Healthcare Clinic Operations & Revenue Analytics using SQL

A healthcare analytics SQL project using a multi-table clinic dataset to examine appointment activity, doctor workload, treatments, payments, and insurance coverage.

## Objective

Use SQL to transform and analyze clinic operations data, identify operational trends, and perform data-quality checks across connected healthcare records.

## Dataset

Source: Healthcare Clinic Dataset from Kaggle.

The dataset contains synthetic, CC0-licensed data across patients, doctors, clinics, staff, appointments, treatments, prescriptions, payments, and insurance records.
